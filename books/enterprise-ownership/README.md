# 企业的制度剖面

央企、国企、混合所有制与私企

作者：李钊 · 工作室与出版单位：若谷书房  
第一版 · 1.0 · 2026-11-17

本书从出资、控制、治理、融资、激励、创新与责任切入，分析央企、地方国企、混合所有制企业与私企的真实运行，提供一套可以用于具体企业的比较与核验方法。

真实案例包括中国联通混改公告、重庆水务 2025 年报、格力电器 2025 年报和美的集团 2025 年报。公告与年报只支持相应时点和披露事实，不被用作普遍绩效证明。综合案例与示意情境均明确标注，不对应真实企业。
