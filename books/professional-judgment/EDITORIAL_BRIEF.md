# 《答案之后：AI 时代的专业判断》编辑约定

日期：2026-11-10；作者：李钊；出版单位：若谷书房。

- 读者：知识工作者、管理者、专业人士。
- 承诺与范围：定义问题、区分事实与推测、核验来源、检验反方、分级处理风险、有效复核、承担责任。每章解决一个明确问题，提供操作路径、冲突与失败边界。
- 写法：商业通识与方法；用多行业模拟案例说明判断机制。先交全书可连续阅读的短篇幅初稿，后续按作者反馈扩写；不以提纲替代正文，不承诺书中方法已获实证验证。
- 结构：前言、连续 7 章、结语、可填写的附录与来源说明。章标题统一为 `## 第01章　章名`，节标题用三级标题。章节不强制重复固定小节，保留解释与叙事节奏。
- 案例：除标注真实案例／研究外，虚构人物、公司、过程、金额和结果均为原创模拟，章节显式标注。不得沿用既有书中的虚构业绩作为真实证据。无真实访谈、真实客户账目或实际工具运行结果。
- 证据：现有书稿只作内部写作来源，不作独立实证。外部材料采用官方原文，正文在有限事实处用 `S01` 等编号加实际来源链接；自拟方法与推演明确其性质。无来源的效率数字、真实客户背书和行业普遍结论不进入正文。
- 素材处理：保留既有书中的证据分类、完整成本和验证责任；深化为本书独立问题。具体产品教程、未定位的《智能生活》材料、无出处成功故事不进入正文。
- 视觉：初稿采用文字与小型表格；暂不生成封面或插图，未来制作再确定视觉方案。
- 主稿：`manuscript/book.md` 为唯一内容源，不维护并行组装稿。书名与章序可在共同审定时调整。
- 验收：章号连续，无占位正文；引用能对应来源账本；模拟边界清楚；数字可复算；不复制其他作品长段内容；如实记录已做与未做的审阅。
- 交付：本次仅 Markdown 主稿、编辑约定、来源、修订和初稿检查记录。作者确认后再制作 PDF、EPUB 与 Markdown 阅读包，实际检查通过后上架。
